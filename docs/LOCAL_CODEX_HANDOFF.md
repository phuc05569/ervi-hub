## Architecture, ownership and cleanup
`Scope` owns connections/tasks/instances with reverse-order cleanup. Early `_G.RNG_HUB_STOP` registration prevents duplicate sessions, even interrupted initialization. `Game` supplies client-visible character/style/roll evidence. `RollAdapter` isolates the existing zero-argument RollAttack protocol; `AutoRoll`, `Rarity`, `M1State`, `TargetState`, `SafeZoneState` are testable logic. `PositionHold` transactionally restores anchoring; `SafeZone` owns activation origin and observer scope. `Targets` is read-only observation.

`FeatureSchema` defines persistent feature defaults/types/ranges; `Settings` handles compatibility/imports; `Ui` registers shared controls; `Registry` supplies literal multiword ranked search and removes destroyed nodes. `App` composes pages, main geometry, key dispatch and search; `Expansion` composes expanded features. `FloatingWindow`/`WindowGeometry` share drag/resize/clamp/persistence. `Logo` and `StatusBar` are new modules. `Theme`/`Locale` handle appearance/EN-RU labels; logs/game values remain verbatim.

`PropertyOverrides` snapshots actual normalized writes, guards self events and restores only values it still owns. `PlayerTools` binds new characters and releases old state. `World` owns lighting/Atmosphere/blur and Reset Camera; Freecam code removed. `Visuals`/`VisualPolicy`/`VisualPreview` enforce target, skeleton, range and cadence budgets: Auto10Hz stationary/30Hz moving, explicit10/20/30, ranked full/far updates, lazy bones/resources. Release all overlays/listeners on disable/unload. `RuntimeActions` supplies rejoin/bounded server-hop/restore-safe FPS cap (requires getter+setter; 0 restores/leaves prior). `Session` owns anti-AFK/reconnect/queue-on-teleport; `BootLog` records bounded real stages and prior-run log.

Avoid duplicate character observers where shared state suffices, per-frame property fights, duplicate workers or orphaned GUIs. Do not overwrite subsequent game-owned property changes. Status updates run at4Hz only while visible; benchmark native logo/static geometry and overlays locally before optimizing.
